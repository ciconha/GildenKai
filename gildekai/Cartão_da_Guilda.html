Sobre a GitHub Guild

A Lenda

Num reino distante de bits e bytes, a GitHub Guild reúne os mais habilidosos artífices do código. Cada membro é reconhecido por suas contribuições ao mundo digital.

O Gildenkai é o órgão regulador que concede autorizações de desenvolvimento de software aos membros qualificados.

Como se Juntar

  1. Forje seu cartão de guilda usando seu nome do GitHub
  2. Contribua para projetos open-source
  3. Suba de rank através de commits e estrelas
  4. Compartilhe seu cartão em seu perfil
